# PRD — quicksnip（快截）

- 版本：v0.1（草案）
- 日期：2026-10-15
- 发起人（Sponsor）：项目发起人（用户本人，负责方向拍板与阶段门审批）
- 项目经理：数字员工「项目经理」
- 状态：待评审

## 1. 背景与问题

微信截图（Alt+A）交互优秀，但触发前提是微信客户端常驻后台，资源占用高。目标用户（从本项目发起人扩展到同类痛点用户）需要一款**独立、轻量、开源**的同等体验截图工具。

## 2. 目标

| 维度 | 目标 | 衡量标准 |
| --- | --- | --- |
| 功能 | 复刻微信截图核心交互 | 框选、6 种标注、撤销、保存/复制/贴图全部可用 |
| 资源 | 显著轻于微信常驻 | 空闲内存 < 100MB（PyInstaller 版实测，验收时确认基线） |
| 启动 | 热键即截 | 按热键到遮罩出现 < 500ms（P95） |
| 开源 | 可对外发布 | MIT 协议、README/贡献指南/CI/Release 齐备，无侵权素材 |

## 3. 范围

### 3.1 本期范围（In Scope）

- Windows 桌面端（Win10/11 优先），多显示器适配
- 全局热键唤起（默认 Ctrl+Alt+A，可配置）
- 全屏遮罩 + 鼠标框选
- 标注：矩形、椭圆、箭头、画笔、文字、马赛克
- 撤销；保存（对话框）、复制到剪贴板、贴图悬浮窗
- 系统托盘（截图 / 打开保存目录 / 退出）
- 开源治理：MIT、README、CONTRIBUTING、任务/风险文档、Git 仓库

### 3.2 暂不包含（Out of Scope）

- 截图历史管理库、图床上传、OCR、滚动长截图
- macOS / Linux 正式适配（Linux 仅保证源码可运行）
- 移动端；团队协作标注；云服务

### 3.3 假设

- 技术栈：Python 3.10+ + PySide6（Qt6），理由：跨平台基础好、团队上手快、GUI 能力成熟、打包生态（PyInstaller）成熟。
- 默认热键 Ctrl+Alt+A 与微信默认 Alt+A 错开，避免同机冲突。
- 团队角色沿用既有配置（产品经理/UI/前端/后端/测试 + 项目经理），具体人员名单待发起人确认。

### 3.4 约束

- 不使用微信/腾讯任何商标、图标、素材；交互灵感可借鉴。
- 不引入付费/闭源依赖。
- 阶段门制度：不达标不进下一阶段；DoD = 产出 + 测试通过 + 可演示。

## 4. 用户故事与验收标准

| 编号 | 用户故事 | 验收标准 |
| --- | --- | --- |
| US-1 | 作为用户，我按热键即可开始截图 | 热键按下后 500ms 内出现全屏遮罩；托盘菜单也可触发 |
| US-2 | 作为用户，我可以框选任意屏幕区域 | 拖拽出选区；选区过小时判定无效；Esc 可取消 |
| US-3 | 作为用户，我可以对截图做常用标注 | 6 种工具可切换、可连续标注；画笔轨迹连续；马赛克不可反推原图 |
| US-4 | 作为用户，我可以撤销误操作 | 每次撤销移除最近一条标注 |
| US-5 | 作为用户，我可以保存/复制/贴图 | 保存走系统对话框且默认时间戳命名；复制进剪贴板可粘贴到微信/画图；贴图窗口置顶可拖拽、可再保存 |
| US-6 | 作为多屏用户，我可以在任意屏幕截屏 | 虚拟桌面跨屏选区正确，DPI 缩放 100%/150% 下图像不错位 |
