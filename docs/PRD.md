- 版本：v0.2（草案，已纳入文字提取与翻译需求）
- 日期：2026-10-15
- 发起人（Sponsor）：项目发起人（用户本人，负责方向拍板与阶段门审批）
- 项目经理：数字员工「项目经理」
- 状态：待评审（评审人：产品经理 + 发起人）

## 1. 背景与问题

微信截图（Alt+A）交互优秀，但触发前提是微信客户端常驻后台，资源占用高。目标用户（从本项目发起人扩展到同类痛点用户）需要一款**独立、轻量、开源**的同等体验截图工具，且保留微信原版的**文字提取**与**翻译**能力。

## 2. 目标

| 维度 | 目标 | 衡量标准 |
| --- | --- | --- |
| 功能 | 复刻微信截图核心交互 | 框选、6 种标注、撤销、保存/复制/贴图、文字提取、翻译全部可用 |
| 资源 | 显著轻于微信常驻 | 空闲内存 < 100MB（PyInstaller 版实测） |
| 启动 | 热键即截 | 按热键到遮罩出现 < 500ms（P95） |
| 隐私 | 图片默认不出本机 | OCR 全程离线；仅用户主动点击翻译时才发送识别文本 |
| 开源 | 可对外发布 | MIT 协议、README/贡献指南/CI/Release 齐备，无侵权素材与内置密钥 |

## 3. 范围

### 3.1 本期范围（In Scope）

- Windows 10/11 桌面端，多显示器适配
- 全局热键唤起（默认 Ctrl+Alt+A，可配置）；系统托盘
- 全屏遮罩 + 鼠标框选
- 标注：矩形、椭圆、箭头、画笔、文字、马赛克；撤销
- 输出：保存（对话框）、复制到剪贴板、贴图悬浮窗
- **文字提取（OCR）**：选区就地识别，结果可编辑、可复制
- **翻译**：对识别文本做翻译，可插拔在线服务，用户自配密钥
- 开源治理：MIT、README、CONTRIBUTING、任务/风险文档、GitHub 仓库与 CI

### 3.2 暂不包含（Out of Scope）

- 截图历史管理库、图床上传、滚动长截图、录屏
- macOS / Linux 正式适配（Linux 仅保证基础源码可运行）
- OCR 离线大模型方案（体积与「轻量」目标冲突，本期不做）
- 移动端；团队协作标注；自建翻译服务

### 3.3 假设与约束

- 技术栈：Python 3.10+ + PySide6（Qt6），理由：跨平台基础好、上手快、GUI 成熟、PyInstaller 打包生态完善。
- OCR 采用 **Windows 系统 OCR API**（Windows.Media.Ocr）：离线、无第三方依赖、体积零增长；约束是**仅 Windows 可用**，且依赖系统已安装对应语言的 OCR 语言包（缺失时需引导用户安装系统语言包）。
- 翻译采用**在线 API + 用户自配密钥**：仓库不内置任何密钥；首个 provider 选型由后端在 T-23 提议、产品经理确认（候选：DeepL / 百度 / 有道）。
- 默认热键 Ctrl+Alt+A 与微信默认 Alt+A 错开，避免同机冲突。
- 不使用微信/腾讯任何商标、图标、素材。
- 阶段门制度：不达标不进下一阶段；DoD = 产出 + 测试通过 + 可演示。

## 4. 用户故事与验收标准

| 编号 | 用户故事 | 验收标准 |
| --- | --- | --- |
| US-1 | 作为用户，我按热键即可开始截图 | 热键按下后 500ms 内出现全屏遮罩；托盘菜单也可触发 |
| US-2 | 作为用户，我可以框选任意屏幕区域 | 拖拽出选区；选区过小时判定无效；Esc 可取消 |
| US-3 | 作为用户，我可以对截图做常用标注 | 6 种工具可切换、可连续标注；画笔轨迹连续；马赛克不可反推原图 |
| US-4 | 作为用户，我可以撤销误操作 | 每次撤销移除最近一条标注 |
| US-5 | 作为用户，我可以保存/复制/贴图 | 保存走系统对话框且默认时间戳命名；复制进剪贴板可粘贴到微信/画图；贴图窗置顶可拖拽、可再保存 |
| US-6 | 作为多屏用户，我可以在任意屏幕截屏 | 虚拟桌面跨屏选区正确，DPI 缩放 100%/150% 下图像不错位 |
| US-7 | 作为用户，我可以提取截图中的文字 | 框选后点击「提取文字」，面板显示可选中、可编辑、可一键复制的文本；识别全程离线，不联网 |
| US-8 | 作为用户，我可以在识别文本后直接翻译 | 结果面板可切换翻译，显示译文；未配置密钥时给出明确配置引导；翻译失败有可读错误提示且不泄露密钥 |
| US-9 | 作为用户，我可以控制隐私 | 默认不联网；只有点击「翻译」才发送文本；密钥可在设置中清除 |

### 4.1 US-7/US-8 详细验收（文字提取与翻译）

| 项 | 标准 |
| --- | --- |
| OCR 准确率 | 在 QA 标准样本集（中英文各 20 张、含代码与表格截图）上，字符准确率 ≥ 95%（口径由 T-25 冻结） |
| OCR 耗时 | 1080p 选区识别 ≤ 2s（P95，本机无独显要求） |
| OCR 离线 | 断网环境下功能完全可用 |
| 语言包缺失 | 未安装对应系统语言包时，提示可读原因与安装引导，不崩溃 |
| 翻译可用性 | 配置有效密钥后，中→英、英→中可用；首个字符返回 ≤ 3s（P95，依赖服务商） |
| 密钥安全 | 密钥不出现在代码、仓库、日志、报错中；可在设置中清除 |
